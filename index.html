        How compression works for each file type
        Images (JPG, PNG, WebP, GIF, BMP, HEIC, TIFF)
        Re-encoded as JPEG (or WebP when the picture has see-through parts, so they stay see-through), lowering quality first and then resolution. iPhone HEIC photos are supported. Location and camera details (EXIF/GPS) are removed along the way.
        Video (MP4, MOV, MKV, WebM, AVI…)
        Re-encoded as MP4 (H.264) at the bitrate that fits your target, dropping resolution (1080p → 720p → 480p…) when needed. Compression runs on your computer's processor, so it takes a while — roughly as long as the video, often longer.
        Audio (MP3, WAV, M4A, FLAC, OGG…)
        Re-encoded as MP3 at the highest bitrate that fits.
        PDF
        Each page is turned into a compressed image and rebuilt into a new PDF. Claude can still read it, but text is no longer selectable in the result.
        Word, PowerPoint, Excel (.docx, .pptx, .xlsx)
        Embedded pictures are downsized and recompressed; your text and layout stay the same.
        Text, CSV, JSON, Markdown, code
        Split into several parts that each fit the limit. CSV/TSV parts keep the header row.
        E-books and CAD files (EPUB, MOBI, DXF, STEP…)
        These are already compact, so Compress puts them in a ZIP. Use the Convert tab to change their format.
        Anything else
        Put into a ZIP at maximum compression. Claude may not open every archive, so use this as a last resort.

        Fit a size aims for the biggest file that's still under your limit. Pick a strength uses fixed settings, so files of all sizes get the same treatment. Shrink by % makes each file at most that share of its current size (often smaller).

        Files already under the target are passed through untouched. Video and audio need a one-time 32 MB download of the converter engine, which your browser then keeps. Scans (OCR), STEP / IGES models and DWG drawings each download their own reader (3 to 11 MB) the first time you use them.
